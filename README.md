StudyTools — Free Edition

StudyTools is a simple student toolkit for studying, planning, and learning.

Features

- Basic calculator
- Percentage calculator
- GPA calculator
- Unit converter
- Study timer
- Notes you can save and reopen
- Study planner

Download

Visit the "GitHub Releases page" (https://github.com/AppMasterM/StudyTools/releases) and choose a release APK. The tested Free Edition release is v1.1.0.

When installing an APK outside Google Play, Android may ask you to allow installation from your browser or file manager. Only install APKs you trust.

Report a problem or suggest a feature

Open an "issue in this repository" (https://github.com/AppMasterM/StudyTools/issues). Describe the problem, your Android version, and the steps to reproduce it. Do not post passwords or other private information.

Support development

If you find StudyTools useful, help the project by sharing it with other students, reporting bugs, suggesting improvements, or contributing to the project.

Custom development or additional features may be available by prior agreement. Discuss the requirements, cost, and payment method before work begins.
